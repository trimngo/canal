# Focus tasks

Inbox items are the source of truth. A task with a due date and positive work estimate appears in Focus, unless completed, deleted, reference-only, or snoozed. A start date is optional; a blank start uses the creation instant inside the daily window, otherwise the next opening, including weekends. Ranking remains independent.

Tap an Inbox item's summary to open its full editor. Categories, notes, timing, work estimate, optional start, and re-ranking live there. The list keeps only inline title editing, completion, read-only summaries and trailing swipe actions for Snooze, Reference and Delete. Categories have a dedicated line with short names; if there are too many to fit, a +count replaces overflow and the editor shows the full paths. Category detail puts Focus before ranked and unranked items. Commitments shows these tasks under their category alongside existing category percentage targets. Category names in Edit goals open the same detail page as Today; Select enables row actions. Separate deadline-goal rows and creation actions are removed.

Log review's Task control can link an entry to any Inbox item, not only Focus tasks. The existing `goalID` / `goalShare` wire fields now retain that task link for compatibility. They do not create extra log segments or duplicate category time. Work matching the task's categories receives its corresponding share; an unlabeled task receives the whole linked duration. Explicit assignment adds task categories if necessary and retains an existing descendant. Editing labels updates the credit, while moving a task to a different category preserves previous credit.

Focus's progress bar fills with actual linked time. Its vertical marker is expected progress at the current time, using linear accumulation over every calendar day in the frozen daily window. The window affects the forecast only: early, late, and weekend logs still count. The day target bar also has an elapsed-day pace marker. A task reaching its estimate is not automatically marked complete.

Old deadline goals migrate to Inbox captures with the same IDs, estimates, dates, categories, and historical log links. Old records remain as migration-marked tombstones for sync and backup compatibility. That marker prevents an out-of-order cloud tombstone from manufacturing a deleted task before its Capture arrives. Migration is idempotent and independent device migrations converge. Legacy decoding/calculation types remain solely for compatibility and reusable pacing; there is no second editable goal record.
